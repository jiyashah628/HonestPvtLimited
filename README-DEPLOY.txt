Included:
- index.html
- style.css and script.js
- 9 collection pages (root-level HTML files)
- all image assets and the HONEST logo in assets/
- 8 original catalogue PDFs in catalogues/ with links from the home page and matching collection pages

Deploy to the ROOT of your new GitHub Pages repository:
1. Extract this ZIP.
2. Upload the CONTENTS of this folder (not the ZIP itself) to the repository root.
3. Commit the changes.
4. In GitHub, open Settings > Pages and ensure the correct branch and /(root) folder are selected.
5. Wait for the Pages deployment, then hard refresh the website.

Important notes:
- Collection HTML pages are placed at the repository root and their local asset links are adjusted accordingly.
- The catalogue PDF for Paintable Moulding was not present among the supplied original catalogue PDFs; that page therefore has no PDF download button.
- Some hero/application images use remote Unsplash URLs, so those specific images require internet access.
- Enquiry form behavior is the static-site behavior in script.js; it is not connected to a backend or email service unless configured separately.
