HONEST DECOR WEBSITE — CATALOGUE IMAGE BUILD

PREVIEW
1. Extract the ZIP file.
2. Open honest-premium-site/index.html in Chrome, Edge, Safari or Firefox.
3. Internet is required for the remote illustrative room photographs and Google Fonts. Extracted catalogue product images are local.

WHAT CHANGED
- Removed the placeholder message from collection pages.
- Extracted individual embedded product images from the supplied catalogues where available.
- Built separate pages for Imprints Vol. 3, Imprints Vol. 2, Alpha Beta, KitKat, Glint & Glow, HONEST Acrylic, AASA, 1FT and Paintable Moulding.
- Added individual product/visual cards and room-application inspiration on each collection page.
- Paintable moulding cards use visible profile labels, sizes and HM references from the provided board.
- No PDFs are embedded as the website catalogue.

IMPORTANT
Some source catalogues are flattened full-page images. For those, the page is split into smaller visual crops and labelled as catalogue visuals rather than inventing product codes. Some extracted images may be swatches or decorative details rather than standalone product images; review before publication. Room photography is illustrative, not verified HONEST installations. Product availability, exact codes and suitability should be confirmed with HONEST. This is a local front-end prototype and is not deployed to honestdecor.in.
